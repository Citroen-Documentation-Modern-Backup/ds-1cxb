C5HB08P0Identification : Éléments du circuit climatisation
REFRIGERATION SIMPLE DEPUIS OPR 3614
1. compresseur
Les véhicules équipés d’une réfrigération R 134 a disposent de deux types de compresseurs :
  • Cylindrée fixe (exemple : SD 7H13)
  • Cylindrée variable (exemple : SD 7V16)
Type d’huile :
  • Compresseur à cylindrée fixe : SP 20
  • Compresseur à cylindrée variable : SP 10
IMPERATIF : Ne jamais utiliser un autre type d’huile.
2. Raccords
Le circuit de climatisation de certains véhicules peut être muni de raccords de type encliquetables.
Figure : c5hp07tc
(1) Raccord encliquetable .
3. pressostat
Figure : c5hp03hc
Le pressostat permet d’enclencher les motoventilateurs en grande vitesse :
  • Réfrigération R 134 a : 17 bars
  • Réfrigération R 12 : 19 bars
4. réservoir déshydrateur
Figure : c5hp03gc
La nature du dessiccant utilisé avec le réfrigérant R 134 a est différente de celle du réfrigérant R 12.
Les réservoirs déshydrateurs compatibles avec le réfrigérant R 134 a sont repérés par une étiquette.
