B1BB4UP0Caractéristiques : Joints de culasse
1. Caractéristiques
1.1. Moteurs XUD7 (161A / A9A) et XUD7T (A8A / A8B / AJZ)
Les joints de culasse sont de texture fibreuse.
1.2. Moteur XUD9 (162 / D9A / D9B /D9D / DJY / DJZ)
Les joints de culasse sont de texture fibreuse.
1.3. Moteurs XUD9T (D8A / D8B / D8C / DHX / DHY), XUD9SD (DHW) et XUD9BSD (DHV)
Les joints de culasse sont de type métallique multifeuilles ou de type métal-élastomère.
